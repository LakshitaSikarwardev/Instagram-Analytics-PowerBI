📊 Instagram Analytics Dashboard – Power BI
This project analyzes Instagram performance data using Power BI to identify engagement patterns, content performance, and growth trends.
The goal is to understand which type of content generates maximum reach and engagement.

## Tools Used
  Power BI Desktop
  Power Query Editor
  DAX

##CSV Dataset

The dataset includes:
Reach
Likes
Comments
Impressions
Engagement
Media Type
Content Category
Traffic Source
Posting Date

## Data Cleaning

Performed in Power Query Editor:
Removed null values
Removed duplicates
Corrected data types
Renamed columns
Removed unnecessary columns

📊 Data Analysis

Created measures such as:
Total Reach
Total Engagement
Total Likes
Total Comments
Followers Growth

Since the dataset contained only one table, no data modeling or relationships were required.

##Dashboard Features
KPI Cards (Total Reach, Engagement, Impressions)
Bar Chart (Engagement by Day of Week)
Pie Chart (Reach by Traffic Source)
Line Chart (Growth Trend Over Time)
Scatter Chart (Reach vs Engagement Analysis)
Matrix Table (Category-wise performance)

# Key Insights
Reels show higher engagement compared to other media types.
Certain days generate higher interaction.
Traffic sources significantly impact reach.
Consistent posting improves engagement growth.
